# Distill: Smallest Coherent Import Unit

## Selected Unit

Import MARS as a MOGT-local research-runner starter kit, not as a canonical Arcanum framework mutation.

The coherent unit is:

1. MOGT run JSONL schema derived from the MARS foundation schema shape.
2. MOGT validator that enforces required common fields and experiment-specific metrics.
3. MOGT fixture examples that use MARS bundle discipline and dry-run gate language.
4. MOGT result-summary/report contracts that preserve MARS evidence-status separation.

## Why This Unit

This unit directly unblocks `SWU-MOGT-HARNESS-001` and creates proof for future Arcanum absorption. It is small enough to validate locally with synthetic fixtures and large enough to test whether MARS patterns fit MOGT's multi-objective game-theoretic evidence needs.

## Absorption Criterion
