# MOGT Raw Inventory Provenance

Purpose: hold the raw retrieved or user-provided source material that backs library-grade inventory entries.

## Directory Rule

Each source should have its own directory:

- `inventory/raw/<source-id>/README.md`

That provenance note may include:

- retrieval URL or source supplier
- pin or version note
- retrieval date
- captured excerpt or note about attached raw files
- whether the raw material is a web excerpt, full text, OCR, or user-supplied copy

## Current State

Open-access sources may be backed by web-retrieved excerpts.

Paywalled or otherwise inaccessible sources should be added through user-provided raw files so later inventorization can point to a real provenance artifact rather than to memory or shorthand notes.
