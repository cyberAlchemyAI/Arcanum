# Claude Shannon Secrecy Systems Tower

Status: active starter tower

Depth: standard

Promotion boundary: local-research-only

## One-Sentence Model

Shannon turns secrecy into a probabilistic transformation system: a message,
key, and cryptogram define what an interceptor can infer, and security is
measured by how much uncertainty remains after the cryptogram is known.

## Main Research Lanes

1. Source lane: read Shannon's paper as a theory of secrecy systems, not as a
   modern protocol-design manual.
2. Notation lane: make `M`, `K`, `E`, transformations, entropy, equivocation,
   redundancy, and unicity distance usable before synthesis.
3. Bridge lane: identify which ideas can teach Arcanum design vocabulary and
   which must remain analogy-only.
4. Extension lane: name the next Shannon and cryptography sources needed for a
   larger tower.

## Closure State

The tower is closed for a starter understanding of "Communication Theory of
Secrecy Systems" and for local operator borrowing decisions. It is not closed
for a full Claude Shannon corpus, modern cryptographic security proofs, or
empirical cryptanalysis.
