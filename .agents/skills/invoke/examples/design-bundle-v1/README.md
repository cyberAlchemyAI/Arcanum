The canonical W3 example is generated by
`development/test_compile_design_source_v2.py`. The fixture deliberately builds
the complete live chain rather than storing stale digests:

1. compile a real Define v2 bundle;
2. compile a normal W1 input bundle;
3. compile and independently validate a W2 candidate;
4. write schema-valid, candidate-bound Distill request, JSONL events, execution
   receipt, and validation result;
5. compile two absent W3 destinations and require byte-identical fifteen-file
   inventories;
6. independently replay-admit one bundle and prove a tampered copy blocks without
   changing submitted bytes;
7. use the genuine v2 bundle as the one admitted predecessor for a fresh W1/W2
   evolution candidate.

Run from the canonical `arcanum/` root:

```text
python3 spells/invoke/development/test_compile_design_source_v2.py
```

publication, or deployment authority.
