# W0: Baseline And Admission

## Decision

After this wave, we know whether one candidate SWU can enter a clean,
evidence-bound Task Session without inheriting undeclared scope.

## Inputs

- approved Invoke package;
- explicit Sigil Development lifecycle acceptance;
- one explicitly selected SWU;
- exact task-local target inventory.

## Actions

1. Revalidate the Invoke package and Dispatch receipt.
2. Confirm `selected_swu` names exactly one declared unit.
3. Generate the task-local Context Builder pack at execution time.
4. Write the exact baseline defined by
   [CLOSEOUT-CONTRACT.md](../shared/CLOSEOUT-CONTRACT.md).
5. Stop if any target contains overlapping unrelated user changes that the
   selected unit cannot preserve.

## Exit Evidence

- selected-SWU record;
- execution-time context pack receipt;
- exact baseline digest;
- preflight pass or bounded blocker.

W0 does not authorize a second SWU.
