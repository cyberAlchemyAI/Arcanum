# Reporting

## Required Final Report

The runtime final report must include:

- changed files,
- ordered SWU completion status,
- validation commands run and results,
- fixture evidence created,
- renderer behavior observed,
- no-promotion/source-authority boundary result,
- extra sources used outside this goal folder and why,
- remaining residue, if any.

## Extra Source Reporting

Extra-source reporting is required.

For every source read outside this goal folder, the development package, and the Refine handoff, report:

- source path,
- gap or uncertainty that justified it,
- whether it changed the implementation.

## Completion Claim

Do not claim `pass` unless the spell, fixtures, and validation report exist and the required validation checks pass.

Use `flag` if the spell is usable but renderer availability or fixture breadth is intentionally partial.

Use `block` if a required gate prevents safe completion.
