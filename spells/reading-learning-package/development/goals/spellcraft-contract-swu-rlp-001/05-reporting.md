# Reporting

## Required Final Report

The runtime final report must include:

- changed files,
- whether `SWU-RLP-001` is complete,
- validation commands run and results,
- contract sections present,
- any extra sources used outside this goal folder and why,
- downstream gaps intentionally left for Task Session or Experiment Harness.

## Extra Source Reporting

Extra-source reporting is required.

If the runtime reads any source not listed in [01-outcome.md](./01-outcome.md) or [03-constraints-boundaries.md](./03-constraints-boundaries.md), the final report must name:

- source path,
- gap or uncertainty that justified it,
- whether it changed the contract.

## Completion Claim

Do not claim completion unless the candidate contract exists and all required verification checks pass or are explicitly reported with a repair/block status.
