# Reading Learning Package Implementation Layering

## Layering Method

Layer value is measured by the learning package decision unlocked:

```text
source trust -> user-shaped preset -> Whisper manuscript -> PDF artifact -> reusable spell evidence
```

Each layer must preserve the core boundary: source authority comes from the tower,
composition authority comes from Whisper/preset choices, and lifecycle authority
comes from Spellcraft.

## Layer Decision Table

| Layer | Decision Question | Minimum Working Unit | Outcome | Promotion Evidence |
| --- | --- | --- | --- | --- |
| L0 Intake And Preset Proof | Can one tower result become an approved preset profile and Whisper composition plan? | Verify tower paths, ask preset menu, run example-driven core interview, emit `preset-profile.yaml` and `composition-plan.md`. | User sees a customized learning package direction before drafting. | Fixture with one tower and one preset passes interview/substrate checks. |
| L1 Manuscript And Source Trace | Can the plan produce a source-backed reading manuscript without false authority? | Generate `manuscript.md` and `source-trace.md` from tower handles and Whisper plan. | User gets a readable package draft with claim traceability. | Source trace covers load-bearing claims; unsupported claims become residue. |
| L2 PDF Assembly And Validation | Can the package render into a stable PDF or explicit renderer gap? | Build `learning-package.html`, render PDF with available renderer, emit validation report. | User gets PDF or a precise blocked renderer route. | Deterministic render command or blocked renderer evidence. |
| L3 Reusable Spell Hardening | Can Spellcraft validate reusable behavior across presets? | Install/adapt spell contract, run fixtures for all presets, observe/reflect. | Candidate spell becomes reusable with validation evidence. | Experiment harness reports pass/flag/block for deep, quick, and medium presets. |

## Layer Deferrals

| Deferred Item | Deferred Until | Reason |
| --- | --- | --- |
| Actual video rendering | After quick-video text/script package proves useful. | User asked for quick-video preset, not video production tooling. |
| Global saved voice profile | After repeated packages show stable preference evidence. | Avoid premature canonical author voice. |
| Multi-tower synthesis | After one-tower package works. | Prevents source-trace complexity from hiding L0 failures. |
| Canonical spell install | Spellcraft validation. | Invoke package is not lifecycle completion. |

## Non-Regression Guardrails

- Missing tower evidence blocks source-backed drafting.
- Preset defaults must be visible and editable.
- Each SCU core must carry example-based evidence.
- PDF polish cannot hide unsupported source claims.
- Quick-video output remains a script/handout unless a video renderer route is
  explicitly added later.
- Custom preset persistence cannot promote user taste into global canon.

## Recommended First Layer

Start with L0 Intake And Preset Proof. It creates the minimum useful artifact
without depending on PDF renderer availability.
