## Operating Rules

1. Before changing invoke behavior, read the relevant mode contract and validation fixture.
2. Keep edits inside `spells/invoke/` unless a root adapter or command must change for invoke to work.
3. Treat other Arcanum changes as source evidence only when they directly affect invoke.
4. Run `./spells/invoke/development/run-validation-fixtures.sh` after contract, fixture, template, or runner changes.
5. Do not treat generated run reports under `spells/invoke/development/runs/` as canonical design input unless the report is explicitly selected as evidence.
6. If a new topic would broaden the session beyond invoke development, create an `invoke handoff` artifact instead of continuing inside this session.
