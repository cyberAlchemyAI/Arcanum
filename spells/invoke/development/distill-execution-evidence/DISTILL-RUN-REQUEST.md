# Distill Run Request

## Objective Confirmation

- Seed: the Define, Design, layering, implementation plan, split work-pack, dispatch route,
  handoff, and gap ledger in this package.
- Target context: an Invoke-authored lifecycle package that is small enough to begin through
  Spellcraft but complete enough to enforce non-gameable Distill evidence and replay Workbench.
- Output artifacts: `DESIGN-DISTILL-VALIDATION.md` and `PLAN-DISTILL-VALIDATION.md`.
- Optimization goal: preserve the smallest coherent architecture and independently executable
  SWUs without smuggling lifecycle acceptance or Workbench readiness.

## Budget

- Design: Standard, one proposal track, Proposer and Balancer, two recursive rounds, one
  reconciliation.
- Plan: Validate, Balancer-led final critique with Proposer repair, bounded to the same two
  role turns.
- Runtime path: true subagents (available in the active runtime).
- Cycle guard: stop after the reconciliation turn or earlier on stable closure/blocker.
