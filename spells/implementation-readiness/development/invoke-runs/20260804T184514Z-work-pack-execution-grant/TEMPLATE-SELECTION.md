# Template Selection

- Define baseline: DomainSpec-style `SPEC.md` and `GLOSSARY.md` companions.
- Design baseline: six-view DomainSpec architecture bundle.
- Plan baseline: standalone implementation layering, implementation plan,
  split Work Pack, execution pack, task contracts, and SWU manifest.
- Target lifecycle family: existing `implementation-readiness` spell; this is
  not a candidate new spell.
- UX companion: not selected because no rendered semantic surface changes.
- Research companion: not selected because current public contracts and the
  implemented plan-once fixture are sufficient source evidence.

Eligibility is unique; no template tie required an operator decision.
