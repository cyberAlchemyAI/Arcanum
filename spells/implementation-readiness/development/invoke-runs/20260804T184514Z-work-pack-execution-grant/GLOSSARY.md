# Glossary

| Term | Meaning |
| --- | --- |
| Work-Pack execution grant | The bounded execution authority created by the combination of an exact Work Pack and a direct instruction to run it. It is not a per-tool approval. |
| Execution intent binding | Automatic runtime record that binds the current Work Pack identity, frontier, scopes, decision policy, and invocation. |
| Execution-entry projection | Small machine-readable Plan output that says whether selection, an owner prerequisite, Task Session, or a blocker is next. |
| Automatic decision | Mechanical, internal, reversible, plan-bounded choice that the runtime records and performs without interrupting the user. |
| Stop decision | Consequential choice or boundary crossing that changes product meaning, scope, recoverability, external effect, cost/risk, or authority. |
| Internal owner hop | Invocation of an installed capability that already owns a declared part of the Work Pack route. |
| Real blocker | Missing evidence, failed critical validation, unresolved semantic choice, scope expansion, unsafe effect, unavailable required owner, or another condition that prevents correct progress. |
| Authorization theater | Repeatedly asking the operator to approve internal tool use already necessary and bounded by the selected Work Pack. |
| Plan-once admission | Existing profile in which semantic plan readiness is audited once and selected-unit material is admitted later without another readiness audit. |
| Fast prerequisite guard | Constant-shape entry check that classifies the execution-entry state before Context Builder or mutation admission work. |
| Owner receipt | Terminal evidence returned by the invoked capability and joined by the router or outer loop. |
| Fresh Task Session | A new one-unit Task Session invocation after prerequisite completion, rather than recursive continuation of a blocked session. |
