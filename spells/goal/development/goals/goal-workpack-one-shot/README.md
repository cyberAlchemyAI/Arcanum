# Goal Folder: Goal Work-Pack One-Shot

This folder packages a compact native Codex `/goal` command plus sidecar
context for executing the full ordered `arcanum/spells/goal` work-pack stream.

## Files

| File | Purpose |
| --- | --- |
| `00-goal-command.md` | Pasteable native Codex `/goal` command. |
| `01-outcome.md` | Whole-stream outcome and completion condition. |
| `02-verification.md` | Wave/SWU evidence matrix and receipt shape. |
| `03-constraints-boundaries.md` | Capability lanes, write scope, and public/private boundaries. |
| `04-iteration-stop.md` | Ordered execution and blocked stop rules. |
| `05-reporting.md` | Final stream reporting requirements. |
| `handoff-pack.md` | Strict Markdown handoff pack for the whole stream. |
| `handoff-index.json` | Structured index for SWUs, tasks, waves, sources, and gates. |
| `CODEX-GOAL-PROFILE.md` | Full codex-goal-profile result. |

## Start Here

Use `00-goal-command.md` as the native command. The runtime should then read
`CODEX-GOAL-PROFILE.md`, `handoff-pack.md`, and `handoff-index.json` before
opening broader context.
