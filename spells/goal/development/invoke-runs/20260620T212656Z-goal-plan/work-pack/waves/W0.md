# Wave W0: Lifecycle Validation

## Layer Mapping

- Layer: L0
- Layer question: After this layer, we know whether the goal source, design, and
  plan packet is coherent enough for lifecycle work.
- Promotion evidence: Spellcraft validation report or named refinement block.

## Included Tasks

| Task | SWUs | Gate |
| --- | --- | --- |
| TASK-GOAL-SPELLCRAFT-VALIDATE | SWU-GOAL-001, SWU-GOAL-002 | ready |

## Entry Gate

- Source contract exists.
- Define-stage spec and definitions exist.
- Design bundle exists.
- Plan bundle exists.
- Public/private boundary remains active.

## Exit Evidence

- SWU-GOAL-001 produces Spellcraft validation evidence.
- SWU-GOAL-002 produces either a staged source-state sync proposal or an
  explicit deferral note.

## Parallelization

None. W0 is serial because runtime write scope depends on Spellcraft validation.

## Stop Conditions

- Spellcraft blocks the packet.
- Validation discovers private data in public artifacts.
- Source-state sync attempts active ledger mutation instead of a staged
  proposal.
