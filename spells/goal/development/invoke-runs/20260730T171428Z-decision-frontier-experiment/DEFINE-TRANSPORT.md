# Define Transport

## Outgoing Frame

- target: Goal spell extension experiment;
- lifecycle owner: Spellcraft;
- authority effect: none;
- objective: fixture-only deterministic decision frontier;
- required boundaries: Craft authority, HITL stop, proposal-only
  reconciliation, decision/execution separation;
- acceptance anchor: DFE-FIX-001 through DFE-FIX-012;
- unresolved: implementation evidence, canonical representation, runtime
  benefit, and SWU selection.

## Design Admission

Design may proceed against this closed frame. Any proposal to add a tracker,
mutate canonical contracts, or merge decision and execution state requires a
Define refresh.
