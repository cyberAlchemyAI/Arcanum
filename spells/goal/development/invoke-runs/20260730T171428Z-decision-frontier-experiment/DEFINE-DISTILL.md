# Define Distill

## Compression

The proposal is not “make Goal use Wayfinder.” It is:

> Test a pure, claim-aware decision-frontier projection on synthetic fixtures
> while Craft remains authority and execution remains separate.

## Retained Tensions

- derived frontier versus durable accepted state;
- decision resolution versus implementation completion;
- automation versus HITL stop;
- reconciliation utility versus mutation authority;
- deterministic fixture proof versus real workflow benefit.

## Removed Scope

Tracker adapters, canonical schema changes, daemons, broad orchestration,
production concurrency, lifecycle promotion, and performance claims are not
needed to test the core mechanism.

## Define Verdict

The objective, actors, requirements, invariants, witnesses, exclusions, and
lifecycle owner are sufficiently precise for Design. No implementation is
authorized.
