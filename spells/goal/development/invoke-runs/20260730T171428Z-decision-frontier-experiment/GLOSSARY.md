# Glossary

| Term | Meaning in this experiment |
| --- | --- |
| Destination | The bounded planning outcome against which decision relevance is judged. |
| Decision Node | One discrete question whose resolution can change what becomes decidable next. |
| Decision Map | Versioned nodes and dependency edges for one destination. |
| Dependency Edge | A directed relation stating that one decision blocks another. |
| Decision Frontier | Open, precise, in-scope, unclaimed nodes whose blockers are resolved. |
| Fog | Material uncertainty that is not yet a precise decision question. |
| Scope Exclusion | An item explicitly outside the current destination boundary. |
| Claim | A digest-bound lease preventing concurrent resolution of one decision. |
| Resolution Receipt | Evidence that a decision owner supplied an answer. |
| Reconciliation Proposal | A non-authoritative proposal for downstream graph changes after resolution. |
| Way Clear Receipt | Evidence that no in-scope precise decision or unresolved fog remains. |
| Execution Node | A Task Session or Goal work unit; explicitly not a Decision Node. |
| Projection | A derived read model that does not own accepted state. |

Upstream wording is adapted to Arcanum boundaries. These terms are
experiment-local and do not add canonical definitions.
