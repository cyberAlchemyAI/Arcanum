# Distill Request

Distill `EvidenceSet` to the smallest coherent unit.

Reject:

- a generic folder of cards;
- a synthesis essay;
- a task-session handoff pack;
- a ledger or dependency graph;
- an ontology authority object.

Preserve:

- stable set id;
- card membership and exclusions;
- selection rationale;
- source trace through cards;
- handoff intent;
- validation status.
