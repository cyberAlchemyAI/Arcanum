## Composed Rules

| Order | Rule ID | Rule | Validation Mode | Validator |
| --- | --- | --- | --- | --- |
| 1 | `artifact.rendering.chart-line-breaks` | Charts and visual artifacts must not rely on literal `\n` sequences for label, legend, title, annotation, or tooltip line breaks. Use `<br>` or renderer-supported rich text. | deterministic | `tools/validate-artifact-constitution.sh` |
| 2 | `artifact.rendering.export-survival` | Prefer explicit HTML or structured markup that survives export, screenshot, and browser rendering. | review | Visual review or renderer-specific test |
| 3 | `artifact.validation.constitution` | Run Artifact Constitution validation before handoff. | deterministic | `tools/validate-artifact-constitution.sh` |

## Conflicts And Overrides

| Conflict | Status | Resolution |
| --- | --- | --- |
| Literal newline may be acceptable in non-chart code or prose. | resolved | The deterministic check is scoped to likely visual artifact paths and likely chart text lines. |
| Generated chart artifacts can contain violations during temporary runs. | resolved | Generated artifacts are ignored by default; durable/source chart artifacts must pass. |

## Validators To Run

```bash
bash -n tools/validate-artifact-constitution.sh
tools/validate-artifact-constitution.sh --self-test
tools/validate-artifact-constitution.sh
```

## Pass Flag Block

- Pass: no literal `\n` appears in chart text lines for source/durable visual artifacts; validator and self-test pass.
- Flag: renderer has rich-text uncertainty that needs screenshot/export review.
- Block: source/durable chart artifact uses literal `\n` in chart text and has no accepted renderer-specific exception.

## Handoff

Use this composition pack as focused governance context for chart or visual artifact tasks. Do not load all constitution development files when these three rules are enough.
