# Research Initial Definitions

Research Initial Definitions creates or revises the informational baseline that
must exist before a governed [`research`](../research/) dispatch is designed.
Each baseline lives in a research-specific working folder beneath a directory
literally named `research` somewhere inside the repository.

It keeps six concerns separate: context, purpose, a refinable research question,
confirmed product constraints, the current evidence baseline, and known gaps.
It deliberately excludes methods, source plans, agents, topology, success
criteria, findings, handoffs, implementation, and proposed solutions.

The canonical contract is [SKILL.md](SKILL.md). The deterministic structural
gate is [scripts/validate_initial_definitions.py](scripts/validate_initial_definitions.py).
