# Stage 2 — Invoke Define · pass

**What W8 IS:** a ux-lessons mode `emit-studio-fitness` that **projects** a `ux-pattern` into a studio `FitnessSignal` candidate (one or more `FitnessVector`s), so a saved UX lesson can bias the studio's explore/exploit selection — *without* ux-lessons running the cycle, the evaluator, or owning the weights.

**What it is NOT:** the studio fitness cycle, the axe/layout evaluator, or the OQ-5 soft-score weights. Those are studio-owned and blocked.

**Open definitional question (for Design):** does this need a *new* mode, or is it an extension of `emit-studio` (which already emits annotation intents)? And what is the buildable-now subset given the build is blocked?
