# UEV-SPEC-001

Use `ux-evidence-validator` in `spec` mode for a bounded frontend scenario:

- target: a dashboard with navigation, a primary form, async save state, and mobile layout,
- viewports: mobile and desktop,
- domain tags: dashboard, data-tool,
- required evidence: screenshots, ARIA snapshots, accessibility output, measurements, trace, findings JSON, residue ledger.

The result should produce a validator-safe scenario outline and separate hard gates from soft UX flags.
