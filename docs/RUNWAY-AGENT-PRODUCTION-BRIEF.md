## Whisper intent substrate

### Resonance core

- Felt meaning: hidden structure becoming legible.
- Tone: cinematic architectural documentary; exact, curious, calm.
- Emotional residue: “I can finally see why a skill is more than a prompt.”
- Value signal: control comes from explicit layers, boundaries, and evidence.
- Forbidden feels: mystical tower, fantasy citadel, cyberpunk control room,
  product commercial, generic AI spectacle, triumphalist automation.

### Relevance core

- Target public: technically curious builders who know what an LLM prompt is but
  have not yet understood a skill as a layered control architecture.
- Reader/viewer state before: “This is a long instruction file.”
- Viewer state after: “The file stacks distinct control functions, and Refine also
  coordinates a separate evidence-producing lifecycle.”
- Authority mode:
  - the 13 layer names, eight bands, three example traces, and ten-stage loop are
    source-backed by the HTML;
  - the tower, elevator, cutaway, light pulse, and rotation are explanatory
    metaphors;
  - trace order is illustrative, not a guaranteed runtime execution order.

### Trajectory core

1. Begin with the misconception: one sheet, one prompt.
2. Reveal the foundation below it.
3. Build the 13-floor tower in conceptual bands.
4. Show discretion, gates, proof, output, and telemetry as different mechanisms.
5. Send one request through the tower as an illustrative reasoning trace.
6. Rotate the building and reveal the ten-stage lifecycle.
7. End on the corrected model: layered control architecture plus evidence route.
