# CyberAlchemy GitHub Pages Site

This folder is the static GitHub Pages surface for the Arcanum repository.

## Pages Source

- Landing page: `docs/index.html`
- Deep guide page: `docs/arcanum-development-loop.html`
- Printable guide: `docs/arcanum-development-guide.pdf`
- Asset folder: `docs/assets/`

The workflow at `.github/workflows/pages.yml` publishes this folder with GitHub Pages.

## Organization Root Note

This repository publishes as a project page:

```text
https://cyberalchemyai.github.io/Arcanum/
```

For the organization root page:

```text
https://cyberalchemyai.github.io/
```

create or use a repository named `cyberAlchemyAI.github.io` and move/copy the `docs/` contents there.
