Layer 0 — Thesis

Arcanum is a framework for creating reusable agent capabilities through governed synthesis. It turns vague intent into artifacts humans and agents can understand, reuse, validate, and improve.

Layer 2 — Three building blocks

Sigil

One reusable agent capability (README.md + SKILL.md). Solves one bounded problem.

registry/SIGILS.md, arcana/README.md

Spell

A workflow that references several sigils and defines phases, shared state, gates, and observability. Never copies sigil internals.

registry/SPELLS.md, spells/README.md

Discipline

A cross-capability practice that shapes many capabilities. Not a registry entry; holds no promotion authority.

disciplines/DISCIPLINES.md
