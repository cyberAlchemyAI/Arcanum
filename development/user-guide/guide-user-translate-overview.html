User / Translate / Guide

A compact view of the learning-support framework: what we are trying to achieve, what has been built so far, and the next steps toward a usable Guide system.

5-minute brief PDF-ready Status: candidate architecture First spell slice: guide-architecture

The Goal

Help a person understand complex systems by adapting explanations to what they already know, while keeping memory, translation, and guidance as separate responsibilities.

Why It Matters

  • User remembers preferences, known domains, concept states, and learning evidence.
  • Translate turns concepts into the user's vocabulary without distorting the target meaning.
  • Guide orchestrates the route: inspect, translate, explain, validate, and propose ledger updates.

The System In One Picture

User

The protected learning ledger.

  • domain anchors
  • vocabulary preferences
  • concept states
  • local glossary
  • receipts and residue
Translate

The meaning bridge.

  • source and target domains
  • term maps
  • analogy limits
  • target definition
  • translation receipt
Guide

The understanding route.

  • frames the target
  • inspects structure
  • calls Translate
  • assembles explanation
  • asks for active evidence

How A Guide Run Works

FrameWhat target are we trying to understand?
InspectFind boundaries, dependencies, data, behavior, and failure modes.
TranslateUse the user's familiar domain, but keep the target definition intact.
ExplainConcrete frame, structure map, limits, and abstraction.
ValidateAsk for teach-back, transfer, or contrast.
ReceiptPropose User-ledger updates; do not write memory directly.

Key Boundaries

Boundary Rule Why
User vs Guide Guide proposes updates; User owns memory writes. Prevents hidden profile mutation.
Translate vs Guide Guide calls Translate; it does not contain translation logic. Keeps Guide general and Translate reusable.
Analogy vs Truth Every bridge must include where it works and where it breaks. Prevents metaphors from replacing the real concept.
Clarity vs Mastery "I understand" means clarified; mastery needs teach-back, retrieval, transfer, or contrast. Keeps the User glossary evidence-backed.
