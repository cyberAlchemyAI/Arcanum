# Translate Glossary

| Term | Status | Meaning |
| --- | --- | --- |
| translate | candidate | Sigil candidate for mapping meaning across vocabularies, domains, and concept frames. |
| source domain | candidate | Domain used as the user's familiar frame. |
| target domain | candidate | Domain where the concept actually belongs. |
| term map | candidate | Source-term to target-term mapping. |
| bridge map | candidate | Analogy/metaphor mapping with limits. |
| primitive alignment | candidate | Mapping from concrete terms to primitives such as schema, behavior, system, validation, or interface. |
| mapping limit | candidate | Explicit warning about where the analogy stops working. |
| target-domain definition | candidate | The truthful definition in the target domain, preserved beside the analogy. |
| translation receipt | candidate | Bounded record of translation strategy, output, limits, and update proposal. |
