# Guide Glossary

| Term | Status | Meaning |
| --- | --- | --- |
| guide | candidate | Spell/orchestrator for helping a user understand a target. |
| guide route | candidate | Ordered path of inspect, research, translate, explain, validate, and receipt steps. |
| guide target | candidate | Artifact, architecture, decision, concept, or plan the user wants to understand. |
| active evidence prompt | candidate | Prompt that asks for teach-back, retrieval, transfer, or contrast. |
| guide receipt | candidate | Bounded summary of the guide route and proposed User ledger update. |
| subagent dispatch | candidate | Bounded delegation to research, x-ray, inventory, or analysis workers. |
| explanation sequence | candidate | Ordered sections that build understanding from concrete to abstract. |
