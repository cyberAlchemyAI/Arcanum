# Stage 02: Invoke Define

Status: `pass`

## Definition

`User` is a candidate Arcanum capability family that owns a protected learning ledger for one operator's evolving understanding, vocabulary preferences, prior-domain bridges, clarification patterns, and mastered definitions.

`Guide` is a candidate companion family that uses the User ledger to choose explanation moves and then returns structured receipts that can improve the ledger after the user resolves a blocker or confirms clarification.

## Primary Users

- A human learning Arcanum, CyberAlchemy, software development, systems thinking, scientific ideas, business architecture, or other abstract domains.
- An agent trying to explain unfamiliar material using the user's already-mastered domains.
- A future installer/onboarding flow that needs a low-friction way to learn the user's prior experience.

## Core Jobs

| Job | Definition |
| --- | --- |
| Profile seed | Capture domains, roles, metaphors, vocabulary, and known primitives at installation time. |
| Clarification support | Track which Guide moves helped the user understand a specific section or blocker. |
| Vocabulary adaptation | Prefer terms, examples, and analogies that have worked for the user before. |
| Bridge explanation | Translate between source domain and target domain without erasing the target concept. |
| Mastery glossary | Preserve confirmed definitions the user can consult later. |
| Generalization | Help the user move from concrete examples to primitives, schemas, systems, and abstractions. |
