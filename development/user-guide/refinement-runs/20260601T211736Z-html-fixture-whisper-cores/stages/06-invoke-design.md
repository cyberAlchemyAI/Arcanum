# Stage 06: Invoke Design

Status: pass, local current-runtime synthesis.

## Design

The paired artifact uses one shared spine:

1. Start with a broad idea.
2. Extract three cores: promise, fit, movement.
3. Compare candidate routes.
4. Apply hard gates.
5. Select a non-dominated candidate.
6. Decompose into parts.
7. Execute one task-session unit.
8. Preserve validation evidence and residue.
