# Composition Plan

## Narrative Thesis

The hard part of making is not converting instructions into objects. It is
discovering which distinctions the object must preserve, then letting the
object expose what the representation missed.

## Model Change

```text
Before:
  clear instruction -> correct execution -> finished artifact

After:
  intention -> chosen representation -> translation -> artifact
       ^                                         |
       |----- validation, residue, repair -------|
```

The second model becomes Craft when the loop can descend into a coherent layer,
validate locally, and recompose. It becomes durable capability when
CyberAlchemy makes objective, discovery, tension, artifact, trace, validation,
and route visible.

## Narrative Instrument

A door is fabricated perfectly from a drawing and installed where requested.
It opens into a wall. The story retains this same door through every act.

The door is useful because it separates several kinds of correctness:

- dimensional correctness,
- component behavior,
- installation correctness,
- passage through the building,
- compliance with an external owner or constraint.

The viewer can therefore watch a test pass without watching the objective pass.

## Visual Grammar

### Persistent Assets

- `ASSET-DOOR-01`: natural ash-wood interior door, simple contemporary joinery,
  matte brass lever, consistent grain and hinge side.
- `ASSET-WALL-01`: white plaster wall between a warm workshop and a cool gray
  corridor.
- `ASSET-BLUEPRINT-01`: off-white drafting paper with graphite line work; exact
  labels added in editorial, not generated in-image.
- `ASSET-RESIDUE-01`: translucent red tracing-paper line that marks a specific
  failed relation.
- `ASSET-THREAD-01`: thin dark-green return thread used only for recomposition.

### Camera Language

- Close inspection expresses local correctness.
- Pulling back reveals context and upper-layer obligations.
- A top-down table isolates a bounded layer.
- Repeating the same camera move before and after repair proves comparison.
- Zooming out into a navigable map introduces CyberAlchemy only after Craft's
  mechanism is complete.

### Motion Language

- Selection: one fact sharpens while alternatives recede.
- Translation: a line passes through a chain and retains or loses relations.
- Residue: the exact mismatch remains as a tracing layer after the object stops.
- Layering: residue becomes the background of a bounded new work surface.
- Recomposition: a continuous thread returns the validated result to the whole.
- Trace: prior layers remain inspectable rather than dissolving.
