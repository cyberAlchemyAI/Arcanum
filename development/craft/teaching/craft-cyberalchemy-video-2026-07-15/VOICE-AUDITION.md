# Craft And CyberAlchemy Video Voice Audition

## Opening

### Projected Copy

Can a perfectly built door be wrong?

### Spoken Copy

Imagine I ask you to build a door. You measure it, cut it, hang it, and test the
lock. It is straight, smooth, and exact. Then we install it, and it opens into a
wall.

So what failed? The door? The plan? Or the belief that making something
correctly is the same as making the right thing?

## Tension

### Projected Copy

The artifact can pass.

The intent can still fail.

### Spoken Copy

This is the strange part: every local test can pass. The hinges move. The latch
catches. The dimensions match the drawing. But the drawing preserved the wrong
distinctions. It knew width and height. It did not know where a person needed to
go.

More precision would not rescue it. We were precise about an incomplete model.

## Reveal

### Projected Copy

Making is a way of learning.

### Spoken Copy

Craft begins where the door goes wrong. You make your best current
understanding concrete, let the artifact answer back, and treat the mismatch as
evidence. Then you decide: repair this layer, create a smaller coherent one, or
change the structure above it.

CyberAlchemy governs that loop so the lesson survives the moment. The artifact
is not the end of thought. It is how thought becomes testable.
