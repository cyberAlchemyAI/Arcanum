### SWU-CRAFT-NATIVE-RECEIPT-004

Goal: execute or simulate the Context Builder owner-stage work through the parent-native surface and write a valid receipt.

- Context Builder skill contract
- Craft validation target artifact

- If the parent runtime cannot execute Context Builder directly, return `block` with exact missing runtime capability.

- generated run receipt path
- optional task-session evidence artifact

Implementation detail:

1. Read the Context Builder stage handoff.
2. Execute the Context Builder stage using the parent/native surface or Task Session with the handoff context.
3. Write the expected receipt file with:

   - artifact paths,
   - validation result,

- A valid Context Builder receipt exists at the expected path.
- Native Refine records the Context Builder stage as receipt-backed, not handoff-only.
- If blocked, the receipt records the exact missing capability or context.

- Receipt JSON exists and `jq empty` passes.
- `evidence-index.json` shows the Context Builder stage with `evidence_kind=receipt` and `receipt_path`.

Execution owner: subagent or local-fallback.
