# Current Arcanum Research

## Summary

The session set out to describe only the Arcanum that exists today before any future-system or migration design. The research scope was expanded to include the artifacts each principal component produces, consumes, or governs and the operational, inconsistency, and complexity problems visible in current evidence. Three governed explorer lanes inspected repository and artifact coverage, runtime composition, and problem claims under the rule `claim <= proof`. Their returns found a broad owner-partitioned system with real bounded witnesses but no evidence for one universally exercised end-to-end runtime. The work distinguished contracts, implementation, fixtures, historical receipts, current executable observations, and independent recomputation instead of grouping them as equivalent proof. It also found that the current-system-map validator reconciles only what its input declares and therefore cannot independently prove discovery of the relevant repository universe. The registered research topology diverged from the canonical Research owner, correctly blocking the synthesis handoff, while the close registrar then rejected the truthful partial-fan-out count and left the dispatch ledger open. At the user's direction, the parent preserved the explorer returns in `research.md` and authored a provisional, explicitly non-skeptic-gated `findings.md` covering all twenty-four registered research questions. No future architecture, migration plan, or edit to the main analysis was produced.
