## Changes

### `tools/arcanum`

When `ARCANUM_RUNTIME_RUNNER=1`, `tools/arcanum --exec` now:

1. resolves the selected command exactly as before,
2. writes a durable runtime handoff under `.arcanum/runtime/handoffs/`,
3. creates a runtime run under `.arcanum/runtime/runs/`,
4. calls `tools/arcanum-runtime-run --adapter codex-exec`,
5. passes `--output` through to the runtime runner,
6. prints the existing summary fields plus runtime evidence fields:
   - `RUNTIME_RUN`
   - `RUNTIME_RESULT`
   - `RUNTIME_STATUS`
7. preserves observer closeout.

Without `ARCANUM_RUNTIME_RUNNER=1`, the existing direct Codex path remains in place.

### `tools/arcanum-runtime-run`

The Codex adapter prompt was repaired after validation exposed a contract leak. Nested Codex is now told:

- do not write runtime artifacts directly,
- do not write requested output directly,
- let the runner own `RESULT.md`, `RUN.json`, `STATUS.json`, `events.jsonl`, adapter profile evidence, and output copying.
