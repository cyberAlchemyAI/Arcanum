## Implementation Summary

`tools/arcanum` now owns runtime adapter selection and optional runtime envelope evidence.

Added command surface:

```bash
tools/arcanum --list-adapters
tools/arcanum --resolve-adapter <adapter-id>
tools/arcanum --exec --adapter <adapter-id> --output <path> <command> <request>
```

V1 adapters:

- `dry-run`
- `codex-exec`

`ARCANUM_RUNTIME_ENVELOPE=1` creates `.arcanum/runtime/runs/<run-id>/` evidence directly from `tools/arcanum`. Successful command execution writes the command response directly to requested `--output` and does not create runtime `RESULT.md`.

`tools/arcanum-runtime-run` is now a deprecated compatibility wrapper over `tools/arcanum --exec --adapter ...`.
