## Implementation Summary

`tools/arcanum` now supports:

```bash
tools/arcanum --get-default-adapter
tools/arcanum --set-default-adapter <adapter-id>
tools/arcanum --exec --adapter <adapter-id> --output <path> <command> <request>
```

Adapter selection precedence is:

1. explicit `--adapter`,
2. `ARCANUM_RUNTIME_ADAPTER`,
3. `.arcanum/runtime/config.json`,
4. compatibility fallback to `codex-exec` when a Codex command surface exists.

`tools/bootstrap_arcanum.sh` now accepts `--default-adapter <adapter-id>` and writes:

```text
.arcanum/runtime/config.json
.arcanum/runtime/adapters/dry-run.json
.arcanum/runtime/adapters/codex-exec.json
```

The installed runtime config records only command surface, default adapter id, and profile paths. It does not store copied Codex config, tokens, SQLite state, model caches, or symlinks. `tools/install_arcanum.sh` documents and forwards the new bootstrap option.

Installed task-session command text now points at `tools/arcanum --exec` plus configured adapter selection instead of native goal-like runtime wording.
