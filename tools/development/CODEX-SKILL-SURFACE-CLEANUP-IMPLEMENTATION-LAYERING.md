# Implementation Layering: Codex Skill Surface Cleanup

## Purpose

Reduce duplicate Codex skill suggestions by making short alias packages the only default discovery-surface install for Arcanum.

## Source Contract

- Refine seed: `tools/development/CODEX-SKILL-SURFACE-CLEANUP-REFINE.md`.
- Installer: `tools/bootstrap_arcanum.sh`.
- Resolver: `tools/arcanum`.
- Repository guidance: `README.md`.
- Legacy command guidance: `arcana/sigil-runtime-installer/README.md`.

## Target And Scope

- Target: Arcanum generated Codex command/skill surfaces.
- Scope: installer behavior, cleanup preview, cleanup execution plan, and validation.
- Current state: duplicate personal skills and duplicate legacy commands exist.

## Non Regression Guardrails

- Do not remove non-Arcanum personal skills.
- Do not delete canonical repository source folders.
- Do not require `.codex/commands` for normal Codex use.
- Preserve explicit legacy compatibility through `--legacy-codex-commands`.
- Keep short aliases as the user-facing names.
