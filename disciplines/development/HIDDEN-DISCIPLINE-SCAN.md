# Hidden Discipline Scan

Status: initial scan
Owner: Arcanum framework
Date: 2026-06-11

## Purpose

Identify discipline-like practices already present in Arcanum so the new discipline layer grows from repository evidence rather than from abstract taxonomy.

## Initial Classification

The first useful division is:

- **canonical disciplines**: schema, artifact constitution, quality bar, validation experiment,
- **implemented disciplines**: observability,
- **active-pattern disciplines**: planning, dispatch, context selection, evidence, definitions, ontology, decision, distillation, residuality, runtime boundary,
- **candidate disciplines**: Craft and UX evidence.

## Beneficial Formalization Criteria

A hidden practice should become a discipline when formalization will improve at least one of:

- long-term consistency across capabilities,
- validator or template reuse,
- evidence and promotion boundaries,
- user-facing route clarity,
- maintenance and reflection behavior,
- prevention of repeated conceptual drift.

## Immediate Recommendations

1. Keep disciplines as a top-level framework-adjacent source surface.
2. Use the catalog as the first stable artifact, not as a registry.
3. Add validator coverage for catalog row shape and required local links.
4. Treat Craft as a candidate discipline, not canonical framework authority.
5. Use future task-session work to harden one discipline at a time.
